# PyParti 🎆

**A fast, beginner-friendly particle system for Pygame.**  
Create explosions, sparks, trails, and more with full control over size, color, duration, and gravity.

## Features
- Emits multiple particles at once
- A randomized velocity for natural effects
- Automatically removes a particle when its lifetime is reached (or considered ‘dead’)
- Optional gravity
- Customizable (Not fully yet)

## Usage
Check out 'example.py' for a full demo of PyParti.

## Notes
- Particle shrinking and other visual effects can be handled externally for full control.
- Avoid extremely high particle counts without optimizing performance.

## Installation
Clone this repository into your project and start using it!

```bash
pip install pygame
```
